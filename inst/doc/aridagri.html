Getting started with aridagri

aridagri analyses the field experiments that agronomists and breeders run every season. Every function takes a data frame and column names, prints a report, and returns an object you can reuse. Set verbose = FALSE to keep only the object.

The examples use six simulated datasets that ship with the package (mothbean_rbd, clusterbean_spd, pearlmillet_met, chickpea_augmented, cowpea_alpha, mungbean_repeated). They mimic arid-zone trials but are not real experimental results.

The report gives the ANOVA, SEm, SEd, CD at your alpha, CV, the relative efficiency of blocking, and treatment means with letters. Missing plots are handled by least squares: treatments are tested after blocks and every pair of means is compared with its own standard error.

plot(res, ylab = "Seed yield (kg/ha)")
